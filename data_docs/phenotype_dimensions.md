# Phenotype Dimensions
This file documents candidate behavioral profile dimensions such as friction sensitivity, override tendency, substitution tendency, context dependence, and related constructs.

This document summarizes the main candidate dimensions for multidimensional behavioral phenotyping.

## Principle

Phenotypes in this project are not assumed to be fixed single categories.
Instead, users may differ along several dimensions at once.

## Candidate dimensions

### 1. Friction sensitivity
How strongly behavior changes when even a small delay or barrier is introduced.

### 2. Habitual stability
How strongly a user remains in an established usage pattern once it has formed.

### 3. Impulsivity / noise dominance
How much behavior appears driven by short-term fluctuations, bursts, or weakly planned opens.

### 4. Threshold dependence
Whether meaningful change occurs gradually or only once a certain level of intervention or internal tension is reached.

### 5. Context dependence
How strongly behavior depends on time, place, task situation, mood, or other contextual anchors.

### 6. Adaptation over repeated exposure
Whether response to friction changes across time through learning, habituation, or strategy shifts.

### 7. Override tendency
How often friction is bypassed or ignored repeatedly.

### 8. Substitution tendency
Whether friction on one app reduces total use or redirects behavior toward another app.

### 9. Network centralization
Whether a small number of apps dominate the user’s behavior or behavior is more distributed.

### 10. Feedback-loop dominance
Whether behavior seems more governed by reinforcing loops or balancing self-regulatory loops.

## Implementation note

Where possible, each phenotype dimension should be represented as:
- a continuous score
- a documented derivation method
- an uncertainty / confidence note

Optional clustering or subgrouping may later be added on top of these dimensions.
